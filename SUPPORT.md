# Support

Use GitHub Issues for reproducible bugs and feature proposals. The repository
does not currently provide guaranteed response times, private implementation
support, or compatibility support for modified forks.

Before opening an issue:

1. test the latest `main` revision;
2. search for an existing report;
3. include browser, operating system, input device, and reproduction steps; and
4. attach console errors or a short recording when they help explain the issue.

Security and conduct reports must use the private process in
[SECURITY.md](SECURITY.md).
